# Settings – Build Plan / To‑Do List

## A. Warehouse Management

- Create and edit warehouses
- Assign address
- Assign managers and workers
- Allow users in multiple warehouses

## B. Warehouse Location Hierarchy

- Configurable levels:
  - Section
  - Aisle
  - Shelf
  - Bay
  - Row
  - Bin
- Enable/disable levels
- Rename levels
- Auto‑generate location codes
- Require location toggle

## C. Bin Management

- Bin as lowest unit
- Unique identifier per bin
- Assign products to bins
- Filter products by manufacturer
- Drag & drop assignment UI

## D. QR Code Configuration

- Toggle QR codes on/off
- Auto‑generate QR per bin
- Downloadable QR list
- QR used for picking, receiving, inventory moves

## E. Warehouse Roles

- Roles:
  - Manager
  - Worker
- Permissions:
  - Managers: pending, overrides
  - Workers: operational flows

## F. Packing & Shipping Settings

- Define box types:
  - Name
  - Dimensions
  - Weight
- Default box options
- Future carrier configuration

## G. UI / UX

- Replace prototype controls with shared components
- Mobile‑first layouts
- Consistent components across modules
